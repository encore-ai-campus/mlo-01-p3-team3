# 다나와 수집 설계

2026-10-16 현재 구현 기준이다. 실행 방법은 [README](../README.md), 날짜별 실험은 [검증 기록](validation_results.md)을 따른다.

## 범위와 기존 샘플 재사용

구현 사이트는 다나와 하나다. 도매꾹 API 호출, 두 출처 간 동일 상품 매칭, 다른 쇼핑몰 방문은 하지 않는다. 브라우저 자동화·차단 우회·MongoDB 저장도 현재 수집기의 기능이 아니다.

첨부 `danawa_sample.py`는 Session·BeautifulSoup 기반 단일 카테고리 첫 페이지 최대 5개·ID 중복 제거·CSV 출력 예제였다. 해당 샘플 자체에는 카테고리 리스트 기능이 없었다. Session 방식, `.dnw-catalog-item`/`li.prod_item`, pcode 식별, URL 결합, 지연 이미지 속성 탐색을 재사용했다. 기존 `spec_text`가 실제 규격을 수집하는 기능은 아니었으며 규격 추출·POST·상세·사진·복구는 이후 추가했다.

## 현재 수집 단계

1. 카테고리와 한도를 검증한다. ID는 숫자 문자열이며 8자리 고정이나 0 채우기를 요구하지 않는다. 중복 카테고리 코드는 거부한다.
2. `config/danawa_categories_71.json`의 71개를 기본 대상으로 사용한다. 기본 상품·페이지·전체 요청 상한은 없다. 기존 5개 파일과 유한한 테스트 설정은 별도로 남긴다.
3. 로컬 POST 템플릿에 없는 카테고리는 자신의 목록 HTML에서 분류 메타데이터를 읽는다. 다른 카테고리의 physicsCate 값이나 URL 숫자를 잘라 만든 추측값으로 대신하지 않는다.
4. 서로 다른 카테고리의 목록을 병렬로 가져오고, 각 카테고리 안의 페이지는 순서대로 요청한다. 결과 병합·체크포인트 저장은 메인 스레드 하나에서 수행한다.
5. 모든 목록 순회가 끝난 뒤 선택된 고유 상품의 상세를 순차 요청한다. 성공한 상세는 같은 작업 재개에서 생략한다.
6. 상세 갤러리 URL을 저장하고, 옵션을 지정한 경우 사진 다운로드를 순차 수행한다. 상세설명 이미지·목록 썸네일은 파일 다운로드 대상에서 제외한다.

기본 POST 템플릿과 자동 분류 준비 경로는 CLI에서 활성화한다. 템플릿 없는 수동 어댑터의 첫 페이지 GET은 기존 HTML 파서 대체 경로다. 템플릿이나 관측 가능한 분류 정보가 없으면 다중 페이지 요청을 임의로 만들지 않는다.

## 요청·병렬·중단 정책

| 항목 | 구현 |
|---|---|
| 목록 작업자 | `--workers`, 기본 2. 스레드별 Session·어댑터 가변 설정 분리 |
| 목록 간격 | `--listing-interval`, 기본 0초. 모든 목록 작업자가 공유 |
| 상세·이미지 간격 | `--interval`, 기본 1초. 순차 요청 시작 간격 |
| 요청 예산 | 목록·상세는 한 RequestClient의 공통 예산. 이미지 요청 예산은 별도 |
| 타임아웃 | 기본 20초. 실패 요청도 요청 횟수에 포함 |
| 빈/반복 페이지 | 카테고리 종료. 사이트 전체 데이터 확보를 보장하는 조건은 아님 |
| 요청/파싱 오류 | 원인과 페이지를 기록하고 카테고리 중단 |
| HTTP 403/429 | 새 요청 중단. 이미 전송한 요청은 종료될 수 있음 |
| 재시도 | 동일 실행에서 자동 반복하지 않음. 같은 작업 재개 시 실패·미처리 구간 처리 |

리다이렉트 자동 추적, Retry-After를 읽어 예약 재시도, CAPTCHA 전용 탐지, 반복 오류 횟수 기반 공통 중단은 구현하지 않았다. 상위 운영 설계와 맞추려면 별도 작업이 필요하다. 단일 `--workers`는 여러 수집 프로세스 사이의 요청량을 통제하지 않는다.

## 중복·카테고리·가격

식별 키는 `source + product_id`다. 같은 ID가 여러 카테고리나 페이지에서 발견되면 상품 레코드 하나에 `categories[]`와 `payload.listings[]` 관측값을 보존한다. 병렬 완료 순서와 무관하게 카테고리는 설정 순서로 정렬한다.

카테고리별 limit은 그 카테고리에서 선택한 고유 상품 수다. 다른 카테고리와 겹치는 상품도 그 카테고리의 선택 수에 포함한다. 전체 total-limit은 모든 카테고리의 고유 상품 수다. 아직 방문하지 않은 카테고리 소속은 알 수 없다.

같은 작업의 성공한 상세·저장 완료 페이지는 다시 요청하지 않는다. 새 작업 ID는 독립 실행이므로 전역 상품 upsert는 하지 않는다. 서로 다른 pcode가 같은 실물 제품인지 추정해 합치지도 않는다.

POST는 `price.min`을 목록 관측 가격으로 정리하고 전체 상품 객체를 보존한다. HTML 카드의 다른 구성 pcode 가격은 `variant_prices`에 별도 보존한다. JSON-LD 집계와 판매처 제안은 구분하고, 판매 제안 수를 재고로 바꾸지 않는다. 목록과 상세 가격을 하나로 강제 덮어쓰지 않는다.

## 상세 추출 우선순위

여러 JSON-LD 블록·배열·`@graph`에서 상품 ID·URL·sku 또는 유일한 이름 일치를 확인한다. 다른 상품 ID를 명시한 Product는 채택하지 않는다. 외부 JSON-LD 컨텍스트나 판매 연결 링크를 방문하지 않는다. JSON-LD 오류가 있어도 HTML 대체 추출을 계속하고 원문과 오류를 보존한다.

- 상품명: 식별된 상세 Product → 목록 이름.
- 제조사·모델·원산지·크기·무게: 상세 명시 속성 → 명시 규격. 제조사는 made_info, 제조사·모델은 목록 API 값도 대체 경로로 사용한다.
- 브랜드: 상세 명시 브랜드 → 목록 API 브랜드. 브랜드로 제조사를 임의 대체하지 않는다.
- 등록월: 상세의 4자리 등록월 → 파서가 허용한 목록 등록월. 2자리 연도는 원문으로 남기고 세기를 추정하지 않는다.
- 설명·규격·키워드: 상세 JSON-LD/HTML을 사용하고 목록 규격·설명도 보완 경로로 사용한다.
- 갤러리: 관측한 상세 사진만 `images[]`에 구성한다. 목록 사진은 `listing_image_url`이다.

값이 없으면 null과 필드 상태를 남긴다. `detail_status=ok`는 인식 가능한 상세 영역 추출을 뜻하며 모든 필드의 값 확보나 이용 검수 완료를 뜻하지 않는다. [필드 명세](data_fields.md)

| 모듈 | 책임 |
|---|---|
| `core.py` | 설정·공통 요청 정책·상품 병합·상세 순회·필드 집계 |
| `parallel.py` | 카테고리별 목록 요청의 제한된 병렬 실행 |
| `danawa.py` | 다나와 목록·상세·갤러리 추출과 정규화 |
| `pagination.py` | POST 템플릿과 목록 결과 레코드 해석 |
| `checkpoint.py` | 파일 기반 원천/가공 결과 보존·이력 검증·재개·출력 잠금 |
| `storage.py` | JSON 교체·JSONL 이력·파일 연결 공통 함수 |
| `media.py` | 이미지 요청·URL 이력 재사용·해시 캐시·manifest |
| `validation.py` | 이미지 바이트·해시·상품·카테고리 연결 검사 |
| `reprocess.py` | 저장 원문 재추출과 상세 적용 공통 로직 |

공통 단계는 Adapter 인터페이스로 구분했지만 다른 사이트 어댑터는 구현하지 않았다. 요청 허용 호스트 정책도 다른 사이트 추가 시 명시적으로 확장해야 한다.

## 저장·재개 경계

원본은 관련 API 상품 객체/목록 카드와 상세 HTML·JSON-LD·추출 근거다. HTTP 헤더·쿠키까지 포함한 통신 전체 기록은 아니다. 추출 payload 해시는 시간·카테고리 설정을 일부 제외하므로 불변 관측 버전 ID나 동일 실물 상품 판정을 대신하지 않는다.

상품별 JSON과 완료 이력을 페이지/상세 단위로 저장한다. 정상 종료·Ctrl+C·명시적 내보내기에서 통합 JSONL을 생성한다. 파일 저장은 DB 트랜잭션이 아니지만 검증된 JSONL 이력을 기준으로 재개한다. 현재 상태의 파일을 한 번에 전부 불변 원천으로 간주하지 않는다. [복구 계약](checkpoint.md)

MongoDB·Kafka·Delta·MySQL로 연결하는 적재 단계는 계획이며 현재 구현에 포함되지 않는다. [연계 경계](pipeline_integration.md)
