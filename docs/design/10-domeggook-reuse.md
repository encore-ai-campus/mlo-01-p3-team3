# 기존 도매꾹 이미지의 템플릿 제작 활용

이 문서는 기존 도매꾹 이미지의 템플릿 제작 용도만 정한다. 실제 사용자 추천은 다나와 상품정보와 내부 저장한 다나와 상품 이미지를 기준으로 한다.

도매꾹 이미지는 **공간 표현용 AI 템플릿을 제작할 때 참고할 자료**로 별도 관리한다. 품목·형태·색상 등 특징을 검토해 새로운 템플릿을 제작하고, 검수한 템플릿 asset과 출처·제작 방식·모델·프롬프트 버전을 기록한다. 원본 이미지를 생성 API에 직접 전달하는 방식은 별도 이용 범위가 확인된 경우에만 적용한다. 원본 보유나 저장 허용만으로 생성·외부 전송 허용을 추정하지 않는다.

도매꾹 원본 이미지, 완성된 템플릿, 다나와 서비스 상품 이미지는 각각 다른 자산 역할과 인덱스 범위로 관리한다. 같은 이미지 파일이나 벡터가 있더라도 상품 관계·출처·이용 조건을 합치지 않는다. 도매꾹 이미지는 현행 추천의 검색어 생성·카테고리 수집·Gold 발행·광고 서버 조회에 사용하지 않는다.

템플릿 제작은 [템플릿 설계](08-template-generation.md), 다나와 상품 준비는 [데이터 파이프라인](02-data-pipeline.md), 추천은 [광고 서버](07-ad-server.md)를 따른다.
