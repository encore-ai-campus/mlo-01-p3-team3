# 페이지·기능 구현 범위

기준일 2026-10-18 · [전체 작업현황](../작업현황.md) · 현재 코드 대조 기준. 브라우저 실기기 재검증과는 구분한다.

## 1. 사용자 화면

| 화면 | 경로 | 접근 | 구현된 기능 | 경계 |
| --- | --- | --- | --- | --- |
| Home | `/` | 누구나 | Sketch · On 브랜드, 소개, 시작 버튼, Home→편집 flow 연결, 계정 메뉴 | 광고 없음 |
| 공간 편집 | `/editor/`, `/editor/<project_id>/` | 새 작업 누구나, 기존 작업 소유자 | 사진·그림·텍스트·설명/스타일·통합 이력·공간 만들기 | 생성은 모의 |
| 결과 | `/results/<result_id>/` | 소유자 | 결과 가구 조작, 원본 비교, 상품 추천, PNG, 재시작 3종, 회원 저장 | 실제 AI/실상품 아님 |
| 회원가입 | `/accounts/signup/` | 비회원 | 아이디·비밀번호·확인·닉네임, 서버 검증, 성공 안내 1회와 자동 로그인 | 이메일·소셜 인증 없음, 광고 없음 |
| 로그인 | `/accounts/login/` | 비회원 | 아이디·비밀번호·안전한 next 이동, 현재 브라우저 미귀속 작업 연결 | 비밀번호 찾기 없음, 광고 없음 |
| 회원정보 | `/my/profile/` | 로그인 | 닉네임 변경, 현재 비밀번호 확인 후 비밀번호 변경·세션 유지 | 아이디 변경·탈퇴 없음 |
| 찜 목록 | `/my/wishlist/` | 로그인 | 본인 찜 조회·해제 | 실상품 사양 비교 없음 |
| 프로젝트 목록 | `/my/projects/` | 로그인 | 본인 프로젝트/버전 보기, 비교할 두 버전 선택 | 타인 공유·검색 없음 |
| 프로젝트 상세 | `/my/projects/<id>/` | 본인 | 버전별 PNG·편집 복원 | 삭제·공유 정책 없음 |
| 이미지 비교 | `/my/compare/?left=<version>&right=<version>` | 두 버전 모두 본인 | 저장한 이미지 두 장 나란히 비교 | 자동 차이 분석 없음 |

템플릿은 [sketch/templates/sketch](../../../sketch/templates/sketch/home.html), 라우트는 [sketch/urls.py](../../../sketch/urls.py), 회원 저장은 [library.py](../../../sketch/library.py)에 있다.

## 2. 편집기

| 묶음 | 구현 내용 | 현재 제한/동작 |
| --- | --- | --- |
| 사진 | 파일 선택·drop·예시 공간·자르기 | 10MiB, 2,500만 픽셀 이하. EXIF 보정 후 최대 변 2,048px JPEG로 편집 |
| 화면 크기 | 가로폭에 맞추고 사진 비율로 높이 결정 | 고정 세로 높이로 잘라 보여주는 방식 아님 |
| 공통 입력 | Pointer Events, pointer capture, touch-action 제어 | mouse/touch/pen 입력. 기기 자체의 모든 펜 속성 지원을 보장하는 것은 아님 |
| 펜 | 자유 획·색·두께·겹친 획 연결 | 연결/그룹 규칙에 따라 함께 이동 |
| 지우개 | 지나간 영역만 부분 삭제·크기 표시 | 사진 자체를 지우는 도구는 아님, 색 설정 숨김 |
| 채우기 | 연결 영역 flood fill·분리선 경계·부모 요소 이동 연계 | 픽셀 run 마스크. Illustrator 같은 벡터 면 연산 아님, 선 두께 숨김 |
| 텍스트 | 사진 클릭 위치에 직접 입력·이동/크기·선택 후 색 변경 | 사진 위 텍스트 200자. 선 두께 대신 글자 크기 |
| 도형 | 사각형·타원·직선·화살표, 이동·크기·선 두께 | 외곽선 선택으로 빈 내부에 다른 요소 삽입. 그룹 전 내부 요소는 독립 |
| 영역 선택 | 영역으로 여러 요소 선택·그룹/해제·복사/붙여넣기·삭제 | 별도 ‘선택’ 툴 없이 영역 선택. 색/선 두께 숨김 |
| 작업 이력 | 사진 업로드/자르기·스케치·설명·스타일 공통 Undo/Redo | 첫 사진 업로드부터 이력 생성. Undo/Redo는 작업 삭제 API가 아님 |
| 단축키 | Ctrl+Z / Ctrl+Y / Ctrl+C / Ctrl+V | 텍스트 입력과 선택 도구 문맥을 구분 |
| 설명/스타일 | 별도 1,000자, 크림 패브릭/오크 우드/세이지 그린 중 최대 1개 | 스케치 없이 사진+설명으로 진행 가능 |
| 생성 시작 | 상단·우측 입력부·모바일 하단 ‘공간 만들기’ | 성공 후 같은 작업은 편집 잠금, 별도 결과로 이동 |

직접 카메라 촬영 버튼, 그리고 싶은 가구를 미리 고르는 탭, 중복 사진 입력 버튼, 수정 가능한 화면 제목은 없다. 구현 근거는 [editor.html](../../../sketch/templates/sketch/editor.html), [editor.mjs](../../../sketch/static/sketch/editor.mjs), [paint.mjs](../../../sketch/static/sketch/paint.mjs)다.

## 3. 결과와 상품 추천

결과 제목은 ‘ID 님이 원하시는 “품목”을 생성하였습니다’ 형식이며 실제 예측 신뢰도를 뜻하지 않는다. 모든 획/도형을 모아 하나의 모의 가구를 생성한다. 획마다 여러 상품을 겹쳐 넣는 흐름은 사용하지 않는다.

생성된 가구를 끌거나 모서리/키보드로 크기를 바꿀 수 있다. ‘품목·가구 배치 수정’에는 검색 품목과 **사진 대비 가로·세로 %**가 있고 3D 실측 규격은 아니다. 배치 변경은 버전 검사 후 저장하며 실행 취소·다시 실행·처음 배치로를 제공한다. 품목 변경은 검색 조건 수정이며 실제 모델 재생성이 아니다.

| 버튼/영역 | 동작 |
| --- | --- |
| 새로운 공간 / 원본 사진 | 편집용 배경 사진과 현재 배치 비교. 기존 가구를 자동 인식한 결과가 아님 |
| 이미지 내려받기 | 서버에 저장된 최신 배치의 결과 PNG 다운로드. 미저장 중 입력과 동일하다고 단정하지 않음 |
| 처음부터 다시 그리기 | 같은 사진·스케치 비움, 생성 직전 입력을 유지하는 기능과 분리 |
| 스케치 수정하기 | 생성 직전 문서와 설명/스타일을 복원해 새 작업으로 편집 |
| 다른 상품 검색하기 | 새 사진부터 시작할 작업 생성 |
| 프로젝트에 저장 | 회원에게만 제공. 현재 결과를 개인 프로젝트의 버전으로 보관 |
| 선택한 물체의 상품 찾기 | 결과 물체/버전을 기준으로 별도 추천 실행 |
| 예시 상품 3개 | 모의 이미지·표시명·가격 미정·판매 링크 없음, 선택/비선호·회원 찜 |
| 조건 변경·다시 시도 | 추천 조건/물체 버전 확인, 오류 후 요청 재시도 |

결과 작업 JSON 다운로드 버튼과 중복 합성 이미지 다운로드 버튼은 사용자 화면에서 제거했다. 내부 데이터 조회 API는 남아 있으며 소유권 검사를 거친다. 구현 근거는 [result.html](../../../sketch/templates/sketch/result.html), [result.mjs](../../../sketch/static/sketch/result.mjs), [platform_views.py](../../../sketch/platform_views.py)다.

## 4. 계정 상태·광고 자리·모바일

가입/로그인 시 현재 브라우저 방문 ID의 아직 계정 없는 작업만 연결한다. 뒤로가기·계정 전환 시 서버 상태와 접근 가능 여부를 다시 확인한다. 이미 다른 계정에 귀속된 작업은 가져오지 않으며 다른 계정의 오래된 개인 화면은 숨기거나 지운다.

광고 자리는 편집·결과·My 본문 오른쪽의 300×600px sticky 열이다. 스크롤 상단 24px, 오른쪽 여백 16px, 본문과 분리하는 CSS가 있다. 1280px 미만에서는 숨기며 Home·로그인·가입·운영 화면에는 광고가 없다. 실제 광고 노출·무작위 집행·개인화는 없다. 좁은 화면은 편집 입력 탭·하단 생성 버튼과 단일 열 배치를 사용한다. 실제 스마트폰/태블릿 검증은 별도다.

## 5. 운영 화면

운영 개요 `/ops/`, 이용자 `people/`, 작업 `projects/`, 행동 `events/`, 수집 `collection/`, 광고 `ads/`, 성과 `ad-reports/`, 감사 `audit/`를 제공한다. 작업 상세와 광고 등록/수정 폼은 해당 메뉴의 하위 화면이다. 활성 staff와 권한을 서버에서 검사한다. 메뉴별 상세는 [관리자 안내](../04_운영/관리자_페이지_이용및연동설계.md)를 참조한다.
