## 브라우저 코드

`editor.mjs`는 작업 이력·포인터·텍스트·파일 drop·crop·선택과 요청을, `paint.mjs/geometry.mjs`는 채우기/충돌/그룹/변환 계산을 맡는다. `result.mjs`는 배치 이력·물체 수정·상품 반응·회원 저장을, `library.mjs`는 My 동작을 처리한다. `account-state.mjs`는 서버 인증/소유권과 페이지별 운영 권한을 재확인한다.

`events.mjs`는 행동 전송, `durable-queue.mjs`는 이벤트별 대기/거절 분리, `collector.mjs`는 점별 Raw와 IndexedDB 복구를 처리한다. `operations/preview.mjs`는 읽기 전용 스케치 미리보기이며 편집 렌더러와 맞추어 유지해야 한다.

## 실행과 저장 경계

기본 경로는 프로젝트 BASE_DIR 기준이다. `ROOMPICK_DB_PATH`, `ROOMPICK_MEDIA_ROOT`, `ROOMPICK_RAW_ROOT`로 분리할 수 있다. 기존 이름은 쿠키/데이터 호환을 위해 유지하며 플랫폼 표시명만 SketchOn이다. 테스트에는 실제 DB·media·Raw와 다른 경로를 사용한다.

소스와 migration을 공유할 때 db.sqlite3/media/Raw를 다른 작업본에서 덮어쓰지 않는다. 현재 동작은 작업 트리 기준이며 아직 Git 미추적 상태의 운영 코드가 있으므로 팀 배포 전 버전 관리 반영이 필요하다.
