# 행동데이터·스케치 Raw 수집기준

기준일 2026-10-18 · Raw 계약 **roompick-sketch-1.0.0** 유지. 문서 ver3·서비스 SketchOn 이름과 데이터 계약 버전을 구분한다.

## 1. 수집 대상을 나누는 이유

| 대상 | 무엇을 보관하는가 | 역할 |
| --- | --- | --- |
| Project.document | 최종 표시용 strokes/items와 상대 좌표 | 현재 편집 상태 |
| Project.request_context | 별도 설명·스타일 | 생성 요청 의도 |
| SketchEvent | 클릭·획·도구·사진·결과/상품/회원 행동 | 시점별 사건·분석 연결 |
| Raw JSON | 점별 시간·입력 출처·전체 편집 이력·시작/최종 문서 | 과정 재생·수집 품질 확인 |
| Composition | 확정 생성 입력·결과·배치 | 결과 재현·저장 버전의 원천 |
| RawReceipt | 원문 체크섬·수신·자동 검증·사람 검수 | 운영 메타데이터 |

Raw와 최종 문서, 일반 이벤트는 서로 대체할 수 없다. ‘데이터가 있음’은 학습 정답·사용 동의·실물 상품 연계가 완료됐다는 의미가 아니다.

## 2. 식별자와 인증 시점

| 필드 | 현재 의미 |
| --- | --- |
| Project.owner / writer_id | 같은 브라우저 세션의 익명 방문 ID. 로그인/재시작 때문에 새로 만들지 않음 |
| account | 현재 소유 회원. 미귀속 작업만 로그인 계정에 연결 |
| Project.flow_id | 신규 Home→편집→사진 교체/crop→같은 작업 재시작 흐름. 새 작업/저장 버전 복원은 새 ID |
| SketchEvent.actor_kind / actor_account | 서버가 이벤트를 받은 시점의 인증 스냅샷 |
| SketchEvent.visitor_id / flow_id | 서버 수신 시점의 연결 ID |
| payload.client_actor_kind / reported_actor_kind | 브라우저가 발생 당시 신고한 회원/비회원 구분. 권한 근거로 사용하지 않음 |
| event_time / payload.client_time | 서버 수신 시각 / 클라이언트 신고 시각. 지연·시계 오차 가능 |

로그인 후 과거 비회원 이벤트를 회원 행동으로 소급 갱신하지 않는다. 도입 전 필드가 없는 사건은 unknown/null이다. 브라우저 지문이나 다른 기기 비회원 추적은 구현하지 않았다. 쿠키 삭제·새 브라우저·다른 기기는 새 방문 ID가 될 수 있다.

## 3. Raw 샘플 필드

`schema_version`, `sample_id`, `project_id`, `writer_id`, `created_at`, `label_id`, `label_status`, `quality_status`, `coordinate_system`, `time_origin`, `canvas_width`, `canvas_height`, `device_pixel_ratio`, `project_width`, `project_height`, `strokes`, `operations`, `initial_document`, `final_document`, `final_active_stroke_ids`, `duration_ms`, `undo_count`, `submission_reason`, `result_id`가 필수다. `capture_status`는 선택 필드이며 complete/limited를 구분한다.

- 자유 스케치 label_id는 null, label_status는 unverified, quality_status는 pending으로 수집한다. 운영자가 검수했다고 원문 필드를 덮지 않는다.
- 좌표는 normalized_xy_top_left_down, 시간 원점은 first_pointerdown_ms다. 표시 문서 좌표 0~1과 달리 Raw에는 캔버스 바깥 점도 남을 수 있다.
- stroke에는 stroke_id/order, pen/eraser, ink_hex, stroke_width_css_px, 캔버스 크기·DPR, pointer_type, end_reason, points가 있다.
- 점에는 x/y/t, down/move/up/cancel, native/coalesced/synthetic, in_bounds가 있다. 지원되는 입력에서 pressure/tilt_x/tilt_y·크기 정보를 추가한다. 없는 압력 정보를 실측한 것으로 만들지 않는다.
- operation에는 op_id/type/t/client_time/target_stroke_ids/target_item_ids/document_patch가 있다. upsert/remove/order를 재생해 final_document와 일치하는지 검사한다.
- final_active_stroke_ids와 undo_count도 재생 결과와 확인한다. 최종 지워진 획은 final_document에서 빠져도 Raw 과정에는 남을 수 있다.

## 4. 제한과 품질 상태

샘플은 4MiB 이하의 엄격한 UTF-8 JSON이다. NaN/Infinity·다른 작업/방문 ID·잘못된 필드·재생 불일치는 거부한다. Raw는 최대 1,000획/1,000작업·합계 100,000점, 시간 범위 최대 7일을 검사한다. 표시 문서는 최대 1,000획/100개 요소·획당 10,000점/합계 100,000점 등 별도 제약이 있다. 세부 상한은 [raw_samples.py](../../../sketch/raw_samples.py)와 [validation.py](../../../sketch/validation.py)가 기준이다.

capture_limit, empty_final_document, restored_geometry_without_point_time 같은 검증 경고는 품질 검토 사유다. ‘복구 문서가 있음’이 원래 손 움직임의 점별 시간이 복구됐다는 의미는 아니다.

| 구분 | 상태 | 해석 |
| --- | --- | --- |
| 원문 capture | complete / limited | 브라우저가 수집을 끝까지 보관했는지 |
| 자동 검증 | PASS / REVIEW | 원문 보존 성공, 경고 유무 |
| 수신 오류 메타데이터 | INVALID / CONFLICT / STORAGE_ERROR | 유효성 실패/동일 ID 다른 내용/파일 저장 실패 |
| 사람 검수 | PENDING / APPROVED / REJECTED / HOLD | 원문과 분리한 검수 판단·사유·운영자·시각 |

자동 REVIEW와 사람이 HOLD한 상태는 다르다. PASS/REVIEW이고 원문이 보존된 항목만 사람 승인 대상이다. 사람 승인도 모델의 정답 라벨이나 학습 사용 동의를 자동 생성하지 않는다.

## 5. 전송·저장·복구

일반 이벤트는 이벤트 ID별 로컬 큐에서 전송하고 서버에서 UUID 중복을 검사한다. 전송 성공한 항목만 지우고 거절 자료는 별도 보관한다. 저장소 접근이 막히거나 한도가 차면 메모리 보조가 사용될 수 있으므로 모든 환경에서 영구 보존되는 것은 아니다.

Raw 초안·대기는 IndexedDB에 보관하고 생성/작업 전환/종료/복구 시 제출한다. 종료 시 전송은 CSRF를 포함한 multipart/sendBeacon 보조 경로를 사용한다. 네트워크/저장 실패는 재전송 가능하게 유지하며 다른 계정 데이터와 섞이지 않도록 구분한다. 서버 운영자는 브라우저에만 남은 미전송 데이터를 볼 수 없다.

서버는 JSON을 정규화해 임시 파일에 쓰고 불변 저장한다. 같은 sample_id·동일 바이트는 재전송, 다른 내용은 충돌이다. RawReceipt 체크섬은 HTTP 원문의 공백/들여쓰기 대신 실제 보존한 정규화 바이트를 기준으로 한다. 원문 재색인과 사람 검수는 파일을 변경하지 않는다.

## 6. 미완료 정책

정식 수집 동의·보관 기간·삭제/탈퇴·미성년자·IP 보유·분석 목적·학습용 라벨 승인·데이터 외부 제공·비회원 기기 간 연결 정책은 확정/구현 대상이다. Kafka/Spark·Bronze/Silver/Gold 적재나 광고 서버 전송은 현재 수집 성공을 이유로 완료 처리하지 않는다.
