# 로그 종류와 확인 명령

기준일 2026-10-18 · 명령은 **PowerShell**, 프로젝트 경로는 현재 demo_sketchon이다. 아래 예시는 작성된 명령이며 이 문서를 읽었다고 자동 실행되지는 않는다. 개인정보·원문을 팀 문서/채팅에 무분별하게 복사하지 않는다.

## 1. 무엇을 봐야 하는가

| 질문 | 확인 대상 | 주의 |
| --- | --- | --- |
| 사용자가 어느 도구/버튼을 썼는가 | SketchEvent | 서버 수신 시각과 브라우저 발생 신고 시각을 구분 |
| 실제로 어떤 점을 그렸는가 | Raw JSON strokes/operations | 최종 Project.document만으로 전체 과정 판단 불가 |
| 요청이 실패/제한/성공했는가 | GenerationAttempt + Composition | 도입 전 시도는 없을 수 있음. 최종 결과와 대조 |
| 추천이 지연/충돌/실패했는가 | RecommendationRun | 생성 결과와 별도 실행, lease 만료/재시도 확인 |
| 왜 Raw 검토가 필요한가 | RawReceipt.validation_status/warnings | 사람 검수와 자동 상태를 구분 |
| 누가 원본을 봤거나 심사를 바꿨는가 | OperatorAudit | 로컬 DB 감사 이력이며 외부 변조 방지 저장소는 아님 |
| HTTP 500/파일 오류가 났는가 | 서버 터미널 또는 runtime 로그 | 행동 이벤트의 payload를 대신하는 데이터 아님 |
| 광고 성과가 있는가 | 현재 없음 | 상품 반응 PRODUCT_*와 광고 클릭을 혼동하지 않음 |

## 2. 읽기 전용 확인

```powershell
Set-Location C:\mlo-01-p3-team3\src\demo_sketchon
.\.venv\Scripts\python.exe -B manage.py check
.\.venv\Scripts\python.exe -B manage.py showmigrations sketch operations
.\.venv\Scripts\python.exe -B manage.py shell -c "from sketch.models import Project, Composition, SketchEvent; print({'projects': Project.objects.count(), 'results': Composition.objects.count(), 'events': SketchEvent.objects.count()})"
.\.venv\Scripts\python.exe -B manage.py shell -c "from operations.models import GenerationAttempt; from django.db.models import Count; print(list(GenerationAttempt.objects.values('status').annotate(count=Count('request_id'))))"
.\.venv\Scripts\python.exe -B manage.py shell -c "from operations.models import RawReceipt; from django.db.models import Count; print(list(RawReceipt.objects.values('validation_status', 'review_status').annotate(count=Count('id'))))"
Get-ChildItem -LiteralPath .\data\sketch_raw -Filter *.json | Measure-Object
Get-ChildItem -LiteralPath .\data\runtime -Filter *.log | Sort-Object LastWriteTime -Descending | Select-Object -First 5 Name,Length,LastWriteTime
Get-NetTCPConnection -State Listen -LocalPort 8003
```

개별 사진/Raw/사용자 입력 확인은 가능하면 운영자 로그인 후 보호된 `/ops/` 경로를 사용한다. 전체 파일을 출력하는 대신 필요한 범위와 건수부터 확인한다. 위 shell 집계는 업무 데이터를 수정하지 않지만 DB 접속 권한이 있는 로컬 개발 환경을 전제로 한다.

## 3. 이벤트 내보내기

```powershell
.\.venv\Scripts\python.exe -X utf8 -B manage.py export_sketch_events --project PROJECT_UUID > events.ndjson
```

`PROJECT_UUID`는 실제 작업 ID로 바꾼다. 이 명령은 NDJSON 출력/리다이렉션 파일을 만들 뿐 **Kafka 전송·published_at 변경·consumer offset commit을 하지 않는다**. 회원 정보/텍스트가 포함될 수 있으므로 내보낸 파일은 별도 보관·공유 정책을 적용한다. 기본 DTO가 과거 형식이므로 신규 actor/flow 분석에는 원 DB의 스냅샷 필드도 확인한다. 근거: [export_sketch_events.py](../../../sketch/management/commands/export_sketch_events.py).

## 4. 변경이 있는 관리 명령

```powershell
.\.venv\Scripts\python.exe -B manage.py migrate
.\.venv\Scripts\python.exe -B manage.py configure_ops_roles --username hilee
.\.venv\Scripts\python.exe -B manage.py index_ops_raw --limit 1000
```

위 세 명령은 읽기 전용 진단이 아니다. 각각 DB 스키마, 기존 계정 권한/그룹, Raw 메타데이터를 변경한다. `configure_ops_roles`는 활성 기존 계정만 대상으로 하며 신규 계정/비밀번호를 만들지 않는다. Raw 색인은 원문 파일을 변경하지 않지만 메타 DB를 쓴다. 현재 DB에는 해당 migration이 적용돼 있어 문서 갱신을 이유로 다시 수행하지 않았다.

## 5. 실행/운영 검증 경계

팀원용 실행 예시는 `manage.py runserver 0.0.0.0:8003 --noreload`이고 LAN 주소는 PC에 할당된 IP와 방화벽·ALLOWED_HOSTS가 일치해야 한다. `192.168.0.44`는 기존 데모 설정/접속 주소이며 IP 고정이나 항상 접속 가능함을 문서가 보장하지 않는다. 이번 문서 작업에서 서버를 시작/종료하거나 방화벽을 변경하지 않았다.

운영 이전 시 DEBUG/SECRET_KEY/HTTPS·프록시 IP 신뢰·정적/미디어·백업/복구를 별도 검증한다. 서버 로그가 쌓인다는 사실만으로 구조화 로그/경보·감사 보존 정책이 완성된 것은 아니다.
