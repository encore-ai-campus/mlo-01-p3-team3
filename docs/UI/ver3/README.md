## 현재 범위를 읽는 기준

- **구현**: 해당 코드·URL·템플릿·저장 처리가 존재함을 확인했다는 뜻이다. 상용 운영 인증을 뜻하지 않는다.
- **모의**: 화면과 입력/응답 흐름은 구현됐지만 생성·상품 추천 데이터는 로컬 예시다.
- **미구현/미연결**: 실제 AI, 판매 상품/가격, 광고 송출, Kafka/Spark, AWS 배포 등은 별도 작업이다.
- **검증**: 이번 실행 결과와 과거 2026-10-16의 결과를 분리했다. 이번 Django는 105/106 통과, 날짜 의존 테스트 1건 실패이며 Node 26/26 통과다.

실행 방법은 [프로젝트 README](../../README.md), 현재 소스 근거는 각 문서에 연결했다. DB 집계는 2026-10-18 읽기 전용 스냅샷으로 사용자 수·운영 성과를 의미하지 않는다.
