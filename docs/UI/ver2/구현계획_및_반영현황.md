## 4. 검증과 보존 기록의 범위

당시 계획에는 Django 67개·Node 26개, 격리 서버의 PC/모바일·Raw 재전송·오류 응답·배치 이력·작은 동시 요청 회귀 통과 기록이 있다. migration 전 241개 작업·65개 결과·2,793개 이벤트 ID와 미디어 145개 SHA-256 보존도 **당시 스냅샷**이다. 현재 누적 건수는 [Raw 목록](데모_Raw_데이터_목록.md)을 본다.

당시 백업 기록은 `C:\CHAPTER3\roompick-backups\2026-10-15-extension`이었다. 현재 프로젝트 이동만으로 이 백업도 같은 위치로 옮겼거나 지금 존재한다고 단정하지 않는다. 필요한 복구는 실제 백업 위치를 확인한 뒤 진행한다.

2026-10-16 ver2 정리에서는 문서·현재 소스 대조, 기본 DB의 읽기 전용 조회, 파일 개수·문서 경로·링크 검사를 수행한다. 이전의 실행 검증을 다시 수행했다고 기록하지 않으며 앱 코드·DB·미디어·서버 설정은 바꾸지 않는다.
