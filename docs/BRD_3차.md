# 3차 BRD: 템플릿 기반 공간 구성 및 실제 유사 상품 추천

이 문서는 공간 사진 위 스케치와 텍스트 요구사항으로 템플릿 기반 공간 구성 결과를 제공하고, 결과 속 물체와 유사한 실제 도매꾹 상품의 판매 페이지로 연결하는 프로젝트의 사업 요구사항을 정의한다.

- 상태: 검토용 초안
- 작성일: 2026-10-11
- 수정일: 2026-10-12
- 운영 형태: 내부 비공개 시제품

## 1. 배경과 목표

사용자는 원하는 가구의 위치·형태를 그릴 수 있어도 정확한 상품명이나 검색어를 알기 어렵다. 스케치와 텍스트로 공간 구성 의도를 전달하고 템플릿 기반 결과를 확인한 뒤 유사한 실제 상품을 탐색하여 구매를 판단하도록 돕는다.

**공간 사진 업로드 → 사진 위 스케치·텍스트 요구사항 입력 → 템플릿 기반 공간 구성 → 물체 선택 → 실제 유사 상품 추천 → 상품 비교·선택 → 도매꾹 판매 페이지 이동**

스케치와 텍스트는 원하는 위치·형태·조건을 전달하는 입력이고, 템플릿 기반 공간 구성은 그 의도를 시각화하는 기능이다. 스케치 없이 텍스트 요구사항만 입력한 구성도 지원하며, 다시 그리기·지우기·텍스트 수정으로 결과를 바꿀 수 있다.

공간에는 실제 판매 상품을 직접 배치하지 않고 템플릿을 활용한다. 템플릿 기반 결과와 추천 상품은 유사 관계다. 실제 상품의 치수·가격·옵션은 상품정보로 제공하고 최종 판매 조건은 판매 페이지에서 확인한다.

실제 유사 상품 추천은 사용자의 관심과 관련된 상품을 노출하여 유사 광고 효과를 기대할 수 있다. 상품 노출·선택·판매 링크 클릭으로 반응을 확인하며, 광고 계약이나 광고 수익을 전제로 하지 않는다.

## 2. 대상 사용자

| 대상 | 필요 |
|---|---|
| 내부 시험 사용자 | 사진 위 스케치·텍스트 입력, 템플릿 기반 공간 구성, 물체 선택, 유사 상품 비교, 판매 페이지 이동 |
| 운영자 | 수집·추천 상태 확인, 오류·재처리, 데이터 품질과 사용자 반응 집계 |

## 3. 데이터 활용과 수집 범위

| 데이터 | 활용 |
|---|---|
| 도매꾹 상품정보·이미지 | 실제 추천 후보와 상품 이미지·판매 링크 제공 |
| ABO 이미지·메타데이터 | 이미지 검색 시험과 비교 검증 |
| 사용자 사진·스케치·텍스트·템플릿 기반 결과 | 원하는 위치·형태·조건 전달, 공간 구성과 물체별 상품 검색 입력, 입력·수정 및 이용 반응 기록 |

Gemini는 사용자 사진·스케치·텍스트 요구사항을 해석하고 템플릿 기반 결과의 물체를 분석한다. 도매꾹 이미지는 공간 배치 재료로 사용하지 않고 상품 검색·표시에 활용한다. ABO와 도매꾹은 출처를 구분하며, 최종 판매 연결은 도매꾹 상품으로 제한한다.

| 구분 | 대상 |
|---|---|
| 포함 | 가구 전반: 침대·프레임·매트리스, 소파, 의자, 책상, 테이블·식탁, 수납장·책장·선반 등. 전신·벽걸이 거울, 러그, 큰 수납 제품, 커튼·블라인드, 침구 완제품 |
| 제외 | 작은 장식품·책상 소품·문구류·펜꽂이·소형 정리함·화장품 정리함·손거울·탁상용 소형 화장거울. 교체 부품·조립 자재·충전솜·수예 원재료 |
| 검토 대기 | 포함·제외 상품이 섞인 분류와 크기·용도·품목·이용 조건이 불명확한 상품 |

세부 카테고리·상품명·규격·용도로 대상을 판단한다. 작은 의자·스툴 등 가구는 크기만으로 제외하지 않는다.

가능한 한 많은 유효 데이터를 확보하되 고정 수량을 완료 조건으로 삼지 않는다. 상품 수·다운로드 성공 이미지 수·고유 이미지 수·추천 가능 상품 수를 구분해 집계한다.

### 데이터 보존과 활용 원칙

- **Bronze — 원천 보존:** 허용된 상품 원천 정보와 사용자 사진·스케치·텍스트, 행동 기록을 원천 상태로 보존한다. 사용자 입력은 인식 처리 전에 보존하며, 인식에 실패한 스케치도 요청·처리 상태·실패 사유와 연결해 남긴다.
- **Silver — 정제·표준화:** 원천 데이터의 형식·단위·카테고리를 통일하고 중복·결측·연결 오류를 검증하여 적재한다. 인식 실패 기록은 실패 상태로 구분하며 정상 인식 결과로 처리하지 않는다.
- **Gold — 서비스·광고 활용:** 서비스·광고 서버가 활용할 상품 추천·노출 정보와 기간·상품·카테고리별 반응 집계를 제공한다. 유사 상품 추천의 노출 효과를 분석할 수 있도록 하며, 별도 광고 서버의 구성과 연동 범위는 상세 설계에서 확정한다.

## 4. 비즈니스 요구사항

| ID | 요구사항 | 충족 조건 |
|---|---|---|
| BR-01 | 원천 확보와 보존 | 허용된 상품정보·이미지와 사용자 입력을 Bronze에 보존하고 상품번호·파일·판매 링크·조회 시각·이용 조건을 연결한다. 인식 실패 스케치도 원천과 실패 사유를 유지하며 중복·제외·실패 사유를 관리한다. |
| BR-02 | 공간·스케치 입력 | 파일 선택·끌어다 놓기로 사진을 올리고 사진 위에 그리기·지우기·다시 그리기를 지원한다. 스타일·요구사항과 스케치 위치를 기록하며 두 업로드 방식에 같은 검증을 적용한다. |
| BR-03 | 입력 해석·템플릿 구성·물체 분석 | 스케치의 품목·위치·형태와 텍스트 요구사항을 반영한 템플릿 기반 결과를 제공하고 물체의 품목·영역을 제시한다. 실제 판매 상품을 공간에 직접 배치하지 않으며 불명확한 입력과 분석 오류는 수정·재시도를 지원한다. |
| BR-04 | 실제 유사 상품 추천과 노출 | 템플릿 기반 결과의 선택 물체와 품목이 맞는 실제 상품을 검색하고 원본 이미지·가격·규격·조회 시각을 비교한다. 추천 노출의 유사 광고 효과를 확인할 수 있도록 상품 노출과 반응을 연결한다. |
| BR-05 | 결과 저장과 판매 연결 | 사진·스케치·텍스트 요구사항·템플릿 기반 결과·물체·추천·선택 상품을 연결해 저장하고 해당 도매꾹 판매 페이지로 이동한다. |
| BR-06 | 재탐색 | 다시 그리기·지우기·요구사항 수정·다시 생성·품목/영역 수정·재추천·다른 상품 선택을 지원한다. |
| BR-07 | 사용자 반응 기록 | 스케치와 텍스트의 입력 내용·수정 이력, 생성·추천 요청, 상품 노출·선택·명시적 거절·판매 링크 클릭을 행동 데이터로 기록하고 선택 카테고리를 저장한다. |
| BR-08 | 운영 조회와 복구 | 주요 작업의 상태·실패 원인·재처리를 조회한다. 중복 처리를 방지하고 운영 기록을 별도 보존한다. |
| BR-09 | 정제와 서비스·광고 활용 | Silver에서 상품·입력·행동 데이터를 정제·표준화하고 Gold에서 추천·노출·반응 집계를 제공한다. 운영자가 기간·상품·카테고리별 반응 건수와 반영 시각을 확인하며 동일 이벤트의 재전달을 중복 집계하지 않는다. |

## 5. 완료 기준

| 항목 | 확인 기준 |
|---|---|
| 핵심 흐름 | 사진·스케치·텍스트 입력부터 템플릿 구성·추천·저장·판매 페이지 연결까지 재실행 가능. 스케치 없는 텍스트 기반 구성도 확인 |
| 스케치 처리 | 그리기·지우기·다시 그리기·저장·복원 가능. 화면 크기가 달라도 위치를 복원하고 품목·배치 의도의 반영 여부와 인식 실패를 기록 |
| 수집 범위 | 제외 상품이 이미지 다운로드·검색 등록·추천에서 빠지고 포함 상품은 유지 |
| 데이터 연결·보존 | 시험 상품의 번호·이미지·판매 링크 일치. 허용된 수집 성공 데이터와 접수한 사용자 입력의 Bronze 보존 확인율 100%. 인식 실패 스케치와 실패 사유도 조회 가능 |
| 추천 검증 | 원천 이미지와 템플릿 기반 결과의 검색을 구분해 품목 일치·시각적 유사성·유효 링크를 측정. 공간 구성에 실제 판매 상품 이미지를 직접 배치하지 않는지 확인 |
| 복구 | 생성·다운로드·검색·저장 실패 후 입력과 완료 결과를 유지하고 재시도 가능 |
| 운영 기록 | 작업·재처리·사용자 반응·집계를 대조하고 같은 이벤트 재전달 제외 |
| 텍스트 행동 기록 | 텍스트 입력 내용·수정 이력과 해당 요청·처리 결과를 연결해 조회 가능 |
| 정제·활용 데이터 | Bronze 원천에서 Silver 정제 결과와 Gold 추천·노출·반응 집계까지 추적 가능. 실패 기록은 정상 결과와 구분 |
| 상품 노출 효과 | 노출·선택·판매 링크 클릭 건수와 비율을 확인하여 유사 광고 효과 평가 가능. 구매·매출로 집계하지 않음 |

추천 상품을 템플릿 기반 결과의 물체와 동일 상품으로 단정하지 않는다. 유사도 점수는 정확도 백분율이 아니며, 판매 링크 클릭은 구매 완료나 매출이 아니다.

## 6. 전제조건

- 상품정보·대표 이미지·상세 이미지의 저장·검색 분석·표시는 제공처와 공급사의 이용 조건을 따른다.
- 공간 구성에 사용할 템플릿과 입력 해석·물체 분석·실제 상품 검색에 필요한 서비스를 이용할 수 있어야 한다. 템플릿의 종류와 적용 방식은 상세 설계에서 정한다.
- 상품정보에 조회 시각을 표시하고 최종 가격·재고·옵션은 판매 페이지에서 확인한다.
- 사용자 사진·스케치·텍스트의 외부 AI 전송·보관·삭제 기준을 안내하고 인식 실패 원천에도 같은 보관 기준을 적용한다. 운영 기능의 접근 권한을 관리한다.

상세 기능과 검증 방법은 [3차 PRD](PRD_3차_초안.md)를 따른다.
