## 주요 장애와 대응

| 현상 | 확인된 원인·경계 | 대응과 검증 |
|---|---|---|
| 패키지 설치 보류 | maintainer 승인 목록 비어 있음 | 16종·버전·DEB·스크립트 해시 검토 후 계획 재검증; 범위 밖 자동 승인 금지 |
| 설치 중 예상 외 서비스 | 패키지 알림 경로의 자동 기동 | 감지·중지·한정된 억제 후 재검증; 전체 안전 검사 해제 금지 |
| NiFi 초기 구성 오류 | runtime 경로·인증서 keyUsage·API 속성/권한 불일치 | 구성 수정 후 인증 API·파일·Kafka 실측 |
| 일부 DB 단계 fail-closed | 사전 기록과 실제 서비스 상태 차이 | 합당한 기존 종료 상태 확인 후 해당 단계만 재개; 초기화 반복 금지 |
| Garage Spark 시험 전송 지연 | 의존 JAR 전송 시간 초과 | 기존 고정 버전 로컬 JAR 재사용 후 실제 Worker S3A 검증 |
| NiFi → MySQL 1130 | 연결 출발지에 맞는 업무 계정 계약 없음 | 권한 확대하지 않음; 담당자 승인 및 직접 TLS 재검증 대기 |
| Mongo 인증 검증 보류 | 해당 인프라 실행에서 승인된 인증정보 미확인 | 계정·인증 변경 금지; 팀원의 후속 제한 시험과 구별 |
| AWS 초기 조사 미비 | CLI·원본 VM 위치·인증 미확인 | 후속 인벤토리·CLI 설치로 일부 해소; 이미지 정합성·권한·비용 승인 남음 |

원인과 해결을 확인하지 못한 과거 터미널 오류는 추측으로 해결 완료 목록에 추가하지 않았다. 예를 들어 개인 PC별 로그인 문제를 전체 서버 장애나 비밀번호 유출 문제로 일반화하지 않는다.

## 이번 문서 작업의 검사 범위

이번 PR의 검사 대상은 새 Markdown·수정된 문서 인덱스, 링크·앵커·표·문서 구조, 변경 파일 범위와 민감정보다. 과거 서비스 시험을 이번에 재실행한 것으로 보고하지 않는다.

Bastion의 공식 프로젝트 존재·인벤토리 20대·코드 파일 목록과 보고서 존재를 읽기 전용으로 대조했다. 보호된 원본 파일의 해시 목록은 비공개 감사 위치에 저장한다. 문서에는 비밀정보와 실제 사설 주소·개인 계정·VM 파일을 복제하지 않는다.
