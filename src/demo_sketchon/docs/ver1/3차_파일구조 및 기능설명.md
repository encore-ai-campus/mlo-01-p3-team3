# RoomPick — 3차 파일구조 및 기능설명

- 작성일: 2026년 10월 14일
- 경로 기준: `roompick/`
- 범위: 파일별 역할과 데이터 저장 위치
- 자동 생성되는 개별 사진·이미지 파일명과 `__pycache__`는 생략했다.
- `data/sketch_raw/`는 첫 원본 제출 성공 시 생성되는 경로다.

## 파일구조 및 기능

```text
roompick/
├─ manage.py                              Django 서버 실행·DB 조회·테스트 명령 진입점
├─ requirements.txt                       Django·Pillow 등 실행 의존성 목록
├─ .gitignore                             DB·사진·원본 데이터·테스트 결과의 Git 제외 설정
├─ README.md                              실행 방법·API·데이터 수집·검증 안내
├─ db.sqlite3                             작업·행동 이벤트·검색 결과를 저장하는 DB
├─ Allow-RoomPick-LAN.ps1                  내부망 접속용 Windows 방화벽 설정
├─ lan-firewall.log                       방화벽 설정 스크립트의 실행 기록
│
├─ config/
│  ├─ __init__.py                         Python 패키지 표시
│  ├─ settings.py                         DB·세션·CSRF·데이터 저장 경로 등 Django 설정
│  ├─ urls.py                             전체 요청 경로를 sketch 앱으로 연결
│  └─ wsgi.py                             WSGI 서버 실행 진입점
│
├─ sketch/
│  ├─ __init__.py                         Python 패키지 표시
│  ├─ urls.py                             화면·행동 수집·원본 저장·검색·결과 API 경로
│  ├─ views.py                            화면 응답·사진 처리·데이터 저장·검색·결과 조절
│  ├─ models.py                           Project·SketchEvent·Composition DB 모델 정의
│  ├─ validation.py                       기존 스케치 문서·좌표·요소·행동 이벤트 검증
│  ├─ raw_samples.py                      스케치 원본 검증·편집 이력 재생·불변 JSON 저장
│  ├─ catalog.py                          모의 상품 종류·가격·색상·크기 정의
│  ├─ mock_composition.py                 텍스트 규칙과 샘플 그래픽으로 모의 합성 결과 생성
│  ├─ tests.py                            기존 Django 기능의 회귀 테스트
│  ├─ test_collection.py                  원본 수집 API·중복 처리·접근 제한 테스트
│  │
│  ├─ templates/sketch/
│  │  ├─ home.html                        초기 화면과 시작 버튼 구성
│  │  ├─ editor.html                      사진 업로드·도구·그림판·상품 검색 화면 구성
│  │  └─ result.html                      결과 미리보기·다운로드·재시작 화면 구성
│  │
│  ├─ static/sketch/
│  │  ├─ editor.css                       전체 화면 디자인과 반응형 배치
│  │  ├─ home.mjs                         초기 화면 시작 버튼 클릭 수집
│  │  ├─ editor.mjs                       그림판·사진·편집 기록·검색·원본 수집 연결
│  │  ├─ result.mjs                       결과 가구 이동·크기 조절·저장·다운로드 처리
│  │  ├─ events.mjs                       행동 이벤트 큐·CSRF 요청·임시 보관·재전송
│  │  ├─ collector.mjs                    원본 좌표·시간·편집 이력 수집과 IndexedDB 관리
│  │  ├─ geometry.mjs                     좌표 정규화·이동·크기 조절 계산
│  │  └─ paint.mjs                        채우기·선택 판정·부분 지우기·그룹 계산
│  │
│  ├─ migrations/
│  │  ├─ __init__.py                      Python 패키지 표시
│  │  ├─ 0001_initial.py                  작업·행동 이벤트 테이블 생성
│  │  ├─ 0002_composition.py              검색 결과 테이블 생성
│  │  └─ 0003_composition_version_project_locked.py — 결과 저장 버전·검색 완료 잠금 필드 추가
│  │
│  └─ management/
│     ├─ __init__.py                      Python 패키지 표시
│     └─ commands/
│        ├─ __init__.py                   Python 패키지 표시
│        └─ export_sketch_events.py       행동 이벤트를 NDJSON으로 출력
│
├─ docs/
│  ├─ 데모_변경이력.md                     기능 변경 이유·검증 결과·정책 검토 사항
│  ├─ 3차_페이지_기능구현리스트.md          화면별 기능 구현 목록
│  ├─ 3차_행동데이터 수집기준.md            기존 수집 기준·확장 내용·저장 및 확인 방법
│  ├─ 3차_파일구조 및 기능설명.md           파일구조와 파일별 역할 설명
│  └─ 3차_행동데이터 및 로그 확인 명령어.md DB·원본·브라우저 저장소·서버 로그 확인 안내
│
├─ tests/
│  ├─ geometry.test.mjs                   좌표·이동·크기 조절 계산 테스트
│  ├─ paint.test.mjs                      채우기·선택·지우기·그룹 계산 테스트
│  ├─ collector.test.mjs                  원본 좌표·시간·편집 이력·한도·오류 처리 테스트
│  ├─ browser-check.cjs                   기존 화면 기능의 브라우저 회귀 테스트
│  └─ collection-browser-check.cjs        원본 보관·재전송·복제 탭 보호·실제 저장 테스트
│
├─ media/
│  ├─ rooms/                             업로드하거나 자른 공간 사진 저장
│  └─ results/                           모의 가구가 배치된 합성 PNG 저장
│
├─ data/                                 첫 원본 제출 성공 시 생성
│  └─ sketch_raw/
│     └─ <sample_id>.json                 좌표·시간·편집 이력이 담긴 원본 샘플
│
└─ test-results/
   ├─ home.png                           초기 화면 테스트 캡처
   ├─ desktop-edit.png                   PC 편집 화면 테스트 캡처
   ├─ desktop.png                        PC 결과 화면 테스트 캡처
   ├─ mobile-edit.png                    모바일 크기 편집 화면 테스트 캡처
   └─ mobile.png                         모바일 크기 결과 화면 테스트 캡처
```
