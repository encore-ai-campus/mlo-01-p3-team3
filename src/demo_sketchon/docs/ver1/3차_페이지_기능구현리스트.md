# RoomPick 데모 — 3차 기능구현리스트

- 작성 기준: 2026년 10월 13일
- 범위: 현재 화면과 사용자 조작 기능
- 구성: 대분류는 화면, 중분류는 기능 영역, 세부 항목은 개별 기능
- 상태 기준: 코드에 구현된 기능을 기재하며, 모의 기능과 안내 영역은 별도로 표시
- 기능 ID는 이후 행동데이터 문서와 연결할 수 있도록 부여한다.

## 화면 구성과 이동 흐름

| 화면 | 역할 | 다음 화면으로 이동하는 동작 |
|---|---|---|
| 초기 화면 | 서비스 소개와 시작 | ‘내 공간 꾸미러 가기’ → 스케치 편집 화면 |
| 스케치 편집 화면 | 사진 업로드와 그림·텍스트·도형 편집 | ‘상품 검색하기’ → 모의 결과 생성 후 결과 화면 |
| 결과 화면 | 생성 결과 확인·배치 조절·다운로드 | 다시 그리기·스케치 수정·다른 상품 검색 → 스케치 편집 화면 |

현재는 별도의 ‘결과 생성 중’ 페이지가 없다. 스케치 화면에서 처리 상태를 표시하고, 생성이 완료되면 결과 화면으로 이동한다.

## 1. 초기 화면

| 기능 ID | 기능 영역 | 기능명 | 사용자 동작 및 구현 결과 |
|---|---|---|---|
| HOME-01 | 서비스 안내 | 서비스 소개 표시 | 사진 위에 그림·텍스트·도형으로 원하는 인테리어를 표시하는 서비스임을 안내한다. |
| HOME-02 | 서비스 시작 | 내 공간 꾸미러 가기 | 버튼을 누르면 스케치 편집 화면으로 이동한다. 로그인 없이 시작할 수 있다. |
| HOME-03 | 이용 안내 | 이용 단계 표시 | 사진 업로드 → 아이디어 표시 → 결과 확인의 3단계를 안내한다. |
| HOME-04 | 데모 안내 | 모의 서비스 안내 | 현재는 샘플 그래픽을 사용하며 실제 AI 예측·상품 검색을 수행하지 않는다고 안내한다. |

## 2. 스케치 편집 화면

| 기능 ID | 기능 영역 | 기능명 | 사용자 동작 및 구현 결과 |
|---|---|---|---|
| SKETCH-01 | 사진 | 사진 업로드 | ‘사진 업로드’를 누르고 파일을 선택하면 공간 사진을 그림판 배경으로 표시한다. |
| SKETCH-02 | 사진 | 드래그 앤 드롭 업로드 | 사진 파일 하나를 그림판 영역에 끌어 놓으면 업로드한다. 드롭 가능한 영역을 강조한다. |
| SKETCH-03 | 사진 | 업로드 조건 검사 | JPG·PNG·WebP를 지원한다. 10MB 초과 파일과 읽을 수 없는 이미지는 안내 후 거부한다. |
| SKETCH-04 | 사진 | 사진 교체 | 새 사진을 업로드하면 새 작업으로 전환한다. 편집된 내용이 있으면 교체 여부를 확인하며, 이전 상태는 실행 취소로 복원할 수 있다. |
| SKETCH-05 | 사진 | 자르기 영역 선택 | ‘사진 자르기’를 선택하고 드래그하면 남길 영역을 표시한다. |
| SKETCH-06 | 사진 | 자르기 적용 | ‘선택 영역으로 자르기’를 누르면 선택한 사진 영역으로 새 작업을 시작한다. 기존 표시가 있으면 비워진다는 확인창을 표시한다. |
| SKETCH-07 | 사진 | 자르기 취소 | ‘취소’를 누르면 자르기 선택을 해제하고 펜 도구로 돌아간다. |
| SKETCH-08 | 그림판 | 사진 업로드 전 안내 | 사진이 없는 상태에서는 업로드 안내를 표시하고, 그림 입력을 시작하려 하면 사진을 먼저 업로드하도록 안내한다. |
| SKETCH-09 | 그림판 | 입력 장치 지원 | 마우스·손가락·터치펜 입력으로 그림판을 조작한다. |
| SKETCH-10 | 도구 | 도구 선택 | 선택한 도구를 활성 표시하고 해당 도구의 입력 방식과 설정을 적용한다. |
| SKETCH-11 | 그리기 | 펜 | 사진 위에 자유로운 선과 점을 그린다. |
| SKETCH-12 | 그리기 | 부분 지우개 | 드래그한 범위의 선·텍스트·도형·채우기를 부분적으로 지운다. 배경 사진은 지우지 않는다. |
| SKETCH-13 | 그리기 | 브러시 범위 표시 | 펜·지우개 사용 시 현재 크기에 맞는 원형 표시로 적용 범위를 보여준다. |
| SKETCH-14 | 그리기 | 채우기 | 채우기 도구로 누른 연결 영역에 선택한 색상을 채운다. 윤곽에 연결된 채우기는 해당 윤곽과 함께 편집된다. |
| SKETCH-15 | 도형 | 사각형 | 드래그한 범위에 사각형을 생성한다. |
| SKETCH-16 | 도형 | 타원 | 드래그한 범위에 타원을 생성한다. |
| SKETCH-17 | 도형 | 직선 | 드래그 시작점과 끝점을 연결하는 직선을 생성한다. |
| SKETCH-18 | 도형 | 화살표 | 드래그 방향을 나타내는 화살표를 생성한다. |
| SKETCH-19 | 텍스트 | 텍스트 입력 | 텍스트 도구로 사진 위를 누르면 해당 위치에서 글자를 입력한다. 최대 200자를 입력할 수 있다. |
| SKETCH-20 | 텍스트 | 입력 완료·취소 | Enter 또는 바깥쪽 클릭으로 입력을 완료한다. Shift+Enter로 줄바꿈하고, Esc로 입력을 취소한다. |
| SKETCH-21 | 텍스트 | 기존 텍스트 수정 | 기존 텍스트를 더블클릭하거나 텍스트 도구로 선택해 내용을 수정한다. |
| SKETCH-22 | 설정 | 색상 선택 | 새로 그릴 선·도형, 입력할 텍스트, 채우기에 사용할 색상을 선택한다. |
| SKETCH-23 | 설정 | 펜·지우개·도형 크기 설정 | 슬라이더로 크기를 조절한다. 펜·지우개·도형의 설정값을 구분해 유지한다. |
| SKETCH-24 | 설정 | 선택 요소의 선 두께 변경 | 선택한 펜 획이나 도형의 선 두께를 조절한다. 그룹에 포함된 대상에도 함께 적용한다. |
| SKETCH-25 | 설정 | 입력 글자 크기 설정 | 텍스트 입력 중 글자 크기를 조절한다. |
| SKETCH-26 | 선택·편집 | 개별 요소 선택 | 선이나 도형의 외곽선, 채운 영역, 텍스트를 눌러 선택한다. 도형 내부의 다른 요소는 따로 선택할 수 있다. |
| SKETCH-27 | 선택·편집 | 요소 이동 | 선택한 요소를 드래그하거나 방향키로 이동한다. Shift+방향키는 더 큰 간격으로 이동한다. |
| SKETCH-28 | 선택·편집 | 요소 크기 조절 | 선택 요소의 모서리를 끌거나 ‘크기 조절’을 선택한 뒤 드래그해 크기를 변경한다. |
| SKETCH-29 | 선택·편집 | 영역 선택 | ‘영역 선택’ 또는 선택 도구로 빈 곳에서 드래그해 영역에 완전히 포함된 요소들을 선택한다. |
| SKETCH-30 | 선택·편집 | 그룹화 | 영역으로 선택한 여러 요소를 하나의 그룹으로 묶어 함께 이동·크기 조절한다. |
| SKETCH-31 | 선택·편집 | 그룹 해제 | 선택한 그룹을 해제해 요소를 독립적으로 편집한다. 윤곽과 연결된 채우기는 연결을 유지한다. |
| SKETCH-32 | 선택·편집 | 겹친 펜 획 자동 연결 | 서로 닿거나 겹친 펜 획을 자동으로 그룹 연결한다. |
| SKETCH-33 | 선택·편집 | 복사·붙여넣기 | 선택 요소나 그룹을 복사하고 위치를 조금 옮겨 붙여넣는다. 연결된 채우기와 부분 지우기 상태도 함께 복제한다. |
| SKETCH-34 | 선택·편집 | 선택 삭제 | ‘선택 삭제’ 또는 Delete/Backspace로 선택 요소나 그룹을 삭제한다. |
| SKETCH-35 | 작업 기록 | 실행 취소 | 직전 작업 상태로 돌아간다. 사진 업로드·자르기·스케치 편집을 공통 기록으로 관리하며 최근 20단계를 보관한다. |
| SKETCH-36 | 작업 기록 | 다시 실행 | 실행 취소한 작업을 다시 적용한다. |
| SKETCH-37 | 작업 기록 | 모두 지우기 | 확인창에서 승인하면 그림·텍스트·도형·채우기를 모두 지운다. 배경 사진은 유지한다. |
| SKETCH-38 | 작업 기록 | 같은 탭의 새로고침 복원 | 같은 작업 URL과 저장 버전 조건이 맞으면, 현재 탭에 임시 보관한 편집 내용과 실행 취소·다시 실행 기록을 복원한다. |
| SKETCH-39 | 상태 안내 | 작업 상태 표시 | 획 수·표시 요소 수, 선택 상태, 처리 중 메시지와 오류 안내를 표시한다. |
| SKETCH-40 | 검색 | 상품 검색하기 | 상단·하단 검색 버튼은 같은 기능을 실행한다. 사진과 표시 내용이 있는지 검사한 뒤 모의 결과를 생성한다. |
| SKETCH-41 | 검색 | 전체 입력 묶음 처리 | 그림·텍스트·도형·채우기를 하나의 상품 입력으로 처리한다. 요소별로 상품을 각각 생성하지 않는다. |
| SKETCH-42 | 검색 | 생성 중 조작 제한 | 결과 생성 중에는 편집 조작을 제한하고 처리 상태를 표시한다. 실패하면 오류를 안내하고 조작을 다시 허용한다. |
| SKETCH-43 | 검색 | 결과 화면 이동 | 생성이 성공하면 해당 결과 화면으로 이동한다. 검색이 완료된 원래 작업은 잠기며, 수정은 결과 화면의 재시작 기능으로 진행한다. |

지원 단축키는 Ctrl+Z, Ctrl+Y 또는 Ctrl+Shift+Z, Ctrl+C, Ctrl+V이다.

## 3. 결과 화면

| 기능 ID | 기능 영역 | 기능명 | 사용자 동작 및 구현 결과 |
|---|---|---|---|
| RESULT-01 | 결과 확인 | 모의 예측 문구 표시 | 익명 방문 ID 일부와 모의 예측된 가구·인테리어 종류를 표시한다. |
| RESULT-02 | 결과 확인 | 공간 미리보기 | 업로드한 사진 위에 샘플 가구 그래픽을 배치해 보여준다. |
| RESULT-03 | 결과 확인 | 모의 결과 안내 | 실제 AI 예측·상품 검색 결과가 아니라는 안내를 표시한다. |
| RESULT-04 | 배치 편집 | 가구 선택 | 가구를 누르면 선택 표시와 가구 이름을 보여준다. |
| RESULT-05 | 배치 편집 | 가구 이동 | 가구를 드래그하거나 방향키로 이동한다. |
| RESULT-06 | 배치 편집 | 가구 크기 조절 | 모서리를 끌어 크기를 변경한다. 작은 가구는 ‘선택한 가구 크기 조절’을 사용해 조절할 수 있다. |
| RESULT-07 | 배치 편집 | 배치 자동 반영 | 이동·크기 조절을 완료하면 서버에 저장하고 합성 이미지를 갱신한다. 별도 저장 버튼은 없다. |
| RESULT-08 | 배치 편집 | 취소·저장 실패 복원 | 조작이 취소되면 조작 전 상태로 돌아간다. 저장에 실패하면 마지막으로 서버에 저장된 배치로 복원하고 안내한다. |
| RESULT-09 | 다운로드 | 합성 이미지 내려받기 | 현재 저장된 가구 위치·크기가 반영된 PNG 이미지를 내려받는다. 배치 저장 중에는 다운로드를 제한한다. |
| RESULT-10 | 다운로드 | 결과 작업 데이터 내려받기 | 검색 시 입력 문서, 현재 결과 배치와 관련 정보가 포함된 JSON을 내려받는다. |
| RESULT-11 | 재시작 | 처음부터 다시 그리기 | 같은 사진을 유지하고 표시 내용이 없는 새 스케치 작업으로 이동한다. |
| RESULT-12 | 재시작 | 스케치 수정하기 | 같은 사진과 검색 당시의 스케치·텍스트·도형·채우기를 복원한 새 편집 작업으로 이동한다. 결과 가구의 배치 변경을 원래 스케치에 역으로 적용하지는 않는다. |
| RESULT-13 | 재시작 | 다른 상품 검색하기 | 사진과 표시 내용이 없는 새 작업으로 이동해 새 사진을 업로드할 수 있게 한다. |
| RESULT-14 | 결과 유지 | 새로고침 후 결과 유지 | 같은 결과 URL에서 새로고침하면 서버에 저장된 결과와 배치를 다시 표시한다. |
| RESULT-15 | 상품 안내 | 추천 상품 3칸 표시 | **안내 화면만 구현.** 상품 이미지·판매 사이트가 연결될 자리를 표시하며, 실제 상품 조회·판매 링크는 연결하지 않았다. |

세 가지 재시작 모두 이전 결과를 보존한다. ‘스케치 수정하기’에서는 새 작업의 실행 취소·다시 실행 기록이 새로 시작된다.

## 5. 현재 구현 범위에 포함되지 않은 기능

| 구분 | 현재 상태 |
|---|---|
| 실제 스케치 AI 인식·분류 | 미구현. 텍스트 규칙과 예시 상품으로 모의 처리 |
| 실제 상품 검색·상품 사진·판매 사이트 연결 | 미구현 |
| 한 스케치에서 여러 상품을 독립적으로 인식·추천 | 미구현. 전체 입력을 하나의 상품으로 처리 |
