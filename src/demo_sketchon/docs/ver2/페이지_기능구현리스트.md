# 스케치·온 SketchOn — 페이지 기능구현리스트 ver2

- 정리 기준: 2026-10-16, 현재 소스 및 7차 기능
- 범위: 현재 화면과 사용자 조작 기능
- 구성: 대분류는 화면, 중분류는 기능 영역, 세부 항목은 개별 기능
- 상태 기준: 코드에 구현된 기능을 기재하며, 모의 기능과 안내 영역은 별도로 표시
- 기능 ID는 이후 행동데이터 문서와 연결할 수 있도록 부여한다.

## 화면 구성과 이동 흐름

| 화면 | 역할 | 다음 화면으로 이동하는 동작 |
|---|---|---|
| 초기 화면 | 서비스 소개와 시작 | ‘내 공간 꾸미기’ → 스케치 편집 화면 |
| 스케치 편집 화면 | 사진 업로드와 그림·텍스트·도형 편집 | ‘공간 만들기’ → 모의 결과 생성 후 결과 화면 |
| 결과 화면 | 생성 결과 확인·배치 조절·다운로드 | 다시 그리기·스케치 수정·다른 상품 검색 → 스케치 편집 화면 |

현재는 별도의 ‘결과 생성 중’ 페이지가 없다. 스케치 화면에서 처리 상태를 표시하고, 생성이 완료되면 결과 화면으로 이동한다.

| SKETCH-36 | 작업 기록 | 다시 실행 | 실행 취소한 작업을 다시 적용한다. |

| SKETCH-38 | 작업 기록 | 같은 탭의 새로고침 복원 | 같은 작업 URL과 저장 버전 조건이 맞으면, 현재 탭에 임시 보관한 편집 내용과 실행 취소·다시 실행 기록을 복원한다. |
| SKETCH-39 | 상태 안내 | 작업 상태 표시 | 획 수·표시 요소 수, 선택 상태, 처리 중 메시지와 오류 안내를 표시한다. |

| SKETCH-41 | 검색 | 전체 입력 묶음 처리 | 그림·텍스트·도형·채우기와 별도 설명을 하나의 상품 입력으로 처리한다. 요소별로 상품을 각각 생성하지 않는다. |

| SKETCH-43 | 검색 | 결과 화면 이동 | 생성이 성공하면 해당 결과 화면으로 이동한다. 검색이 완료된 원래 작업은 잠기며, 수정은 결과 화면의 재시작 기능으로 진행한다. |

지원 단축키는 Ctrl+Z, Ctrl+Y 또는 Ctrl+Shift+Z, Ctrl+C, Ctrl+V이다.

### 5~7차에서 확장한 편집 기능

| 기능 ID | 기능 영역 | 기능명 | 현재 구현 |
| --- | --- | --- | --- |
| SKETCH-44 | 사진 | 예시 공간 체험 | 중앙 체험 버튼으로 예시 사진을 업로드해 시작한다. |
| SKETCH-45 | 사진 | 사진 버튼 단일화 | 사진 선택·예시 버튼 한 쌍을 업로드 전 중앙, 업로드 후 제목 옆에서 사용한다. 아래 중복 버튼은 없다. |
| SKETCH-46 | 요청 | 별도 공간 설명 | 최대 1,000자 입력, 글자 수 표시. 사진이 있으면 그림 없이 설명만으로 생성 가능하다. |
| SKETCH-47 | 요청 | 스타일 선택 | 크림 패브릭·오크 우드·세이지 그린 중 최대 한 개를 선택하거나 해제한다. |
| SKETCH-48 | 기록 | 설명·스타일 통합 이력 | 사진·스케치와 같은 Undo/Redo에 포함하고 사진 교체·자르기에서는 유지한다. |
| SKETCH-49 | 반응형 | 모바일 입력 탭 | 사진·스케치 / 설명·스타일 탭과 하단 고정 공간 만들기 버튼을 제공한다. |
| SKETCH-50 | 표시 | 사진 전체폭·비율 유지 | 가로폭 100%, 사진 비율로 높이를 결정하고 결과 화면과 표시 크기를 맞춘다. |
| SKETCH-51 | 설정 | 도구별 설정 표시 | 사용하지 않는 색상·선 크기 설정을 숨긴다. 아래 표를 따른다. |

| 도구·상태 | 표시하는 설정 | 숨기는 설정 |
| --- | --- | --- |
| 펜·도형 | 색상, 선 크기 | 텍스트 입력 설정 |
| 지우개 | 지우개 크기 | 색상 |
| 채우기 | 색상 | 도형 선 크기 |
| 텍스트 입력·재편집 | 색상, 글자 크기 | 도형 선 크기 |
| 영역 선택 기본 | 없음 | 색상, 도형 선 크기 |
| 영역 선택으로 기존 텍스트 선택 | 해당 글자의 색상 | 도형 선 크기·입력용 글자 크기; 글자 크기는 더블클릭 편집에서 조절 |

입력 전 가구 정답이나 추천 품목을 고르게 하는 탭은 없다. 선택한 펜·도형의 선 두께는 해당 펜/도형 도구에서 조절한다. 사진 비율을 유지하는 화면 표시와 업로드 바이트 원본의 실제 픽셀 크기는 구분한다.

## 3. 결과 화면

| 기능 ID | 기능 영역 | 기능명 | 사용자 동작 및 구현 결과 |
|---|---|---|---|
| RESULT-01 | 결과 확인 | 모의 예측 문구 표시 | `[ID] 님이 원하시는 “품목”을 생성하였습니다.`를 표시한다. |
| RESULT-02 | 결과 확인 | 공간 미리보기 | 업로드한 사진 위에 샘플 가구 그래픽을 배치해 보여준다. |
| RESULT-03 | 결과 확인 | 모의 결과 안내 | 실제 AI 예측·상품 검색 결과가 아니라는 안내를 표시한다. |
| RESULT-04 | 배치 편집 | 가구 선택 | 가구를 누르면 선택 표시와 가구 이름을 보여준다. |
| RESULT-05 | 배치 편집 | 가구 이동 | 가구를 드래그하거나 방향키로 이동한다. |
| RESULT-06 | 배치 편집 | 가구 크기 조절 | 모서리를 끌어 크기를 변경한다. Shift+방향키와 가로·세로(%) 입력으로도 조절한다. 별도 크기 조절 모드 버튼은 없다. |
| RESULT-07 | 배치 편집 | 배치 자동 반영 | 이동·크기 조절을 완료하면 서버에 저장하고 합성 이미지를 갱신한다. 별도 저장 버튼은 없다. |
| RESULT-08 | 배치 편집 | 취소·저장 실패 복원 | 조작이 취소되면 조작 전 상태로 돌아간다. 저장에 실패하면 마지막으로 서버에 저장된 배치로 복원하고 안내한다. |
| RESULT-09 | 다운로드 | 합성 이미지 내려받기 | 현재 저장된 가구 위치·크기가 반영된 PNG 이미지를 내려받는다. 배치 저장 중에는 다운로드를 제한한다. |
| RESULT-10 | 내부 조회 | 작업 JSON API 유지·화면 버튼 제거 | 사용자 다운로드 버튼은 제거했다. 개발자는 소유권이 확인된 결과 data API로 입력 문서와 현재 배치를 조회할 수 있다. |
| RESULT-11 | 재시작 | 처음부터 다시 그리기 | 같은 사진을 유지하고 스케치·설명·스타일을 비운 새 작업으로 이동한다. |
| RESULT-12 | 재시작 | 스케치 수정하기 | 같은 사진과 생성 당시의 스케치·텍스트·도형·채우기·설명·스타일을 복원한 새 편집 작업으로 이동한다. 결과 가구의 배치 변경을 원래 스케치에 역으로 적용하지는 않는다. |
| RESULT-13 | 재시작 | 다른 상품 검색하기 | 사진과 표시 내용이 없는 새 작업으로 이동해 새 사진을 업로드할 수 있게 한다. |
| RESULT-14 | 결과 유지 | 새로고침 후 결과 유지 | 같은 결과 URL에서 새로고침하면 서버에 저장된 결과와 배치를 다시 표시한다. |
| RESULT-15 | 상품 안내 | 추천 상품 3칸 표시 | 물체 선택 후 별도 상품 찾기를 실행하면 같은 세 칸에 모의 샘플·반응 버튼을 표시한다. 실제 판매 상품 조회·가격·판매 링크는 연결하지 않았다. |

세 가지 재시작 모두 이전 결과를 보존한다. ‘스케치 수정하기’에서는 새 작업의 실행 취소·다시 실행 기록이 새로 시작된다.

### 5~7차에서 확장한 결과 기능

| 기능 ID | 기능 영역 | 기능명 | 현재 구현 |
| --- | --- | --- | --- |
| RESULT-16 | 배치 기록 | 실행 취소·다시 실행·처음 배치 | 서버 저장 성공 후 이력 반영. 같은 탭 새로고침 복원과 실패 시 이력 보존을 지원한다. |
| RESULT-17 | 비교 | 원본 사진 비교 | 편집에 사용한 공간 사진과 가구 배치 화면을 전환한다. 업로드 원본 .bin 직접 보기와는 다르다. |

| RESULT-19 | 반응 | 상품 선택·비선호 | 마음에 들어요/다른 취향이에요 상태를 표시하고 전용 이벤트로 수집한다. |
| RESULT-20 | 검색 수정 | 실제 가구 선택 | 토글을 열면 생성 가구를 선택한다. 독립된 주황색 검색 박스를 새로 그리지 않는다. |
| RESULT-21 | 검색 수정 | 품목 변경 여부 검사 | 기본 품목과 다를 때만 검색 품목 적용을 활성화한다. 다시 기본값으로 돌리면 비활성화한다. |
| RESULT-22 | 배치 수정 | 가로·세로 비율 입력 | 사진 대비 %로 실제 가구 크기를 변경한다. 입력 완료 시 합성·배치 이력에 자동 저장한다. 실제 cm 치수가 아니다. |
| RESULT-23 | 오류 처리 | 추천 재시도·오래된 응답 차단 | 추천 실패가 생성 이미지를 지우지 않는다. 다른 물체의 늦은 추천을 현재 선택에 표시하지 않는다. |
| RESULT-24 | 버튼 배치 | 배치 기록 아래 4개 동작 | 이미지 내려받기·처음부터 다시 그리기·스케치 수정하기·다른 상품 검색하기를 모은다. |

추천 품목 수정은 검색 조건 수정이며 이미 생성된 가구 사진을 다른 품목으로 다시 합성하는 동작이 아니다. 배치 이동·크기 변경은 실제 PNG를 갱신한다. 원본 비교 대상도 합성 결과와 같은 편집용 사진 크기이며 업로드 바이트 원본 해상도까지 되돌리는 기능은 아니다.
