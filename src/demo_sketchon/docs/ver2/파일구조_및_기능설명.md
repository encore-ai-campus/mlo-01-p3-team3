## 파일과 데이터의 연결

| 목적 | 프런트엔드 | 서버 | 저장 위치 |
| --- | --- | --- | --- |
| 사진 원본 보관 | editor.mjs | views.projects/prepare_photo | media/originals + Project.original_checksum |
| 현재 편집 상태 | editor.mjs·paint.mjs | views.project_detail·validation.document | Project.document/request_context |
| 일반 행동 이벤트 | home/editor/result + events.mjs | views.collect_events | SketchEvent |
| 스케치 원본 | collector.mjs | views.collect_sample·raw_samples.py | IndexedDB → data/sketch_raw |
| 결과 생성 | editor.mjs·platform-api.mjs | views.search·mock_composition.py | Composition + media/results |
| 배치 변경 | result.mjs | views.update_placements | Composition.placements/version + PNG |
| 추천 | result.mjs·platform-api.mjs | platform_views.recommend·platform.provider | RecommendationRun.items/metadata |
| 검색 품목 변경 | result.mjs | platform_views.revise_object | SceneObjectRevision |
| 상품 반응 | result.mjs 별도 내구 큐 | platform_views.item_event | SketchEvent의 PRODUCT_* |

원본 사진·합성 PNG·추천 샘플 이미지는 같은 것이 아니다. `/samples/<placement_id>/<variant>/` 추천 이미지는 로컬 예시를 응답으로 렌더링하며 별도 판매 상품 원본을 수집하는 경로가 아니다. Raw JSON도 Django DB 테이블이 아닌 파일이다.

## 브라우저에만 있는 상태

| 위치 | 내용 | 주의점 |
| --- | --- | --- |
| localStorage | 일반 행동·상품 반응 pending/rejected 이벤트 | 서버 확인 전 임시 보관이며 서버 DB와 별개 |
| sessionStorage | 현재 탭 편집 이력·결과 배치 이력·추천 요청 참조 | 탭 종료·저장소 제한 시 복원을 보장하지 않음 |
| IndexedDB roompick-sketch-v1 | Raw drafts/outbox/failed | 서버 파일이 없다고 즉시 원본이 없다고 판단하지 않음 |
| Django 세션 쿠키 | 익명 방문자의 서버 세션 연결 | 계정·여러 기기를 연결하는 로그인 기능이 아님 |

## 검증 코드 읽는 순서

계산은 `geometry.test.mjs`, `paint.test.mjs`; 수집은 `collector.test.mjs`, `durable-queue.test.mjs`; API 연결은 `platform-api.test.mjs`를 본다. 브라우저 검사는 `browser-check.cjs`, `extension-browser.cjs`, `collection-browser-check.cjs`, `result-extension-browser.cjs`, `ui-layout-browser.cjs`, `revision7-browser.cjs`, `concurrency-browser.cjs`가 맡는다.

현재 경로에서 명령을 실행하는 방법은 [조회 명령어](행동데이터_및_로그_확인_명령어.md), 기능은 [페이지 목록](페이지_기능구현리스트.md), 데이터 관계는 [Raw 목록](데모_Raw_데이터_목록.md)을 참고한다. 이번 문서 작업에서 서비스 코드·DB·미디어는 변경하지 않았다.
