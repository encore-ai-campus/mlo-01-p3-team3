# 파이프라인 통합 문서 안내

파이프라인은 수집기와 별도 책임으로 관리한다. 작업 경로는 `src/data_pipeline/`이다.

통합 설계와 연결 계약은 [파이프라인 통합 설계안](../../data_pipeline/docs/integration_design.md)을 따른다. 이 문서는 위치 안내이며 설계 내용을 중복 보관하지 않는다.

크롤러는 원천·가공 JSONL, 이미지 manifest와 파일, 수집 체크포인트를 제공한다. 적재 측은 대응하는 관측 버전을 검증한 스냅샷을 입력으로 사용하고 기존 수집 재개 상태를 변경하지 않는다. 현재 products는 추출·정규화 중간 결과이며 서비스 MySQL products와 구분한다.

MongoDB·객체 저장소·Kafka·Spark·MySQL 연계와 자동화의 구현·배포·운영 상태는 별도 파이프라인 README와 인계 문서를 기준으로 확인한다. 크롤러 실행만으로 업무 DB 적재까지 시작되는 것은 아니다.
