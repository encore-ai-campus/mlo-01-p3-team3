## 문서와 데이터의 관계

추출 로직의 사실 근거는 `product_collector/`와 `tests/`다. 문서에 쓴 실제 결과는 특정 실행 시점의 값이며 자동으로 최신화되지 않는다. 새로운 실행 결과를 문서에 반영할 때 날짜, 작업 ID, 위치, 검사 범위와 실패 건수를 함께 적는다.

원본 JSON·사진·로컬 요청 헤더·실행별 audit JSON은 이 문서의 첨부 파일이 아니다. Git에서 제외되는 자료이므로 문서만 복제해도 사진이 생기지는 않는다. 전달받을 NAS 위치와 manifest를 별도로 안내한다. 본 문서 묶음에는 주요 검증 수치를 남겨 로컬 audit 파일이 없어도 검사 범위를 이해할 수 있게 했다.

## 표현 기준

- 필드 존재, 값 확보, 다운로드 성공, 파일 무결성, 추천 승인을 각각 구분한다.
- 목록 API 원본, 상세에서 추출한 정보, 수집 메타데이터, 다운로드 측정값을 구분한다.
- 구현한 동작과 제안·미구현 기능을 구분한다.
- 표본 통과를 71개 전체 상품·필드·이미지 검증으로 일반화하지 않는다.
- 단순 중복 URL과 동일 이미지 바이트, 동일 상품 식별은 서로 다른 문제다.
- 사용권·수집 대상·최종 판매 링크 검증이 끝나지 않은 데이터를 승인된 추천 후보로 표시하지 않는다.
