## 현재 상태를 읽는 기준

- 서비스 이름은 **스케치·온 SketchOn**, 실제 로고는 검정 한 줄 **Sketch · On**과 점을 찍는 기하학적 연필이다. 원본 이미지는 [확정 로고 PNG](../../sketch/static/sketch/assets/sketchon-logo-approved.png)에 있다.
- 사진·스케치 또는 설명으로 공간을 생성하고, 결과 물체를 선택한 다음 별도 상품 찾기를 한다. 실제 AI·유사도 검색·판매 API는 연결되지 않은 모의 데모다.
- 현재 Raw 계약 `roompick-sketch-1.0.0`, 쿠키·브라우저 저장소·환경 변수의 `roompick` 식별자는 호환을 위해 유지한다. 이름 변경을 이유로 방문 ID를 바꾸지 않는다.
- 원본 사진, 스케치 Raw JSON, 편집 문서, 생성 PNG, 행동 이벤트와 서버 로그는 서로 다른 데이터다. 데이터가 있다는 사실과 학습용 정답·동의·검수 완료는 구분한다.
- 2026-10-16에는 소스 대조, 문서 링크·경로 확인과 DB 읽기 전용 집계를 수행했다. 과거 Django 67개·Node 26개 통과 기록을 이번 작업에서 재실행한 것처럼 쓰지 않는다. 이는 앞선 문서 정리 시점의 범위다. 이번 8차에서는 회원 기능 구현·테스트·migration을 진행하며 검증 결과를 별도 기록한다.

실행 방법은 [프로젝트 README](../../README.md)를 참고한다. 원본 7개 문서는 수정하지 않고 이 폴더만 현재판으로 사용한다.


## 8차 현재판 안내

로그인·회원가입·My 회원정보·찜 목록·프로젝트 버전 저장/수정/이미지 비교가 추가됐다. 가입 성공 시 “가입이 완료되었습니다!” 안내창을 한 번 표시하고 자동 로그인된 상태로 시작한다. 비회원 생성은 서버 IP별 한국 시간 매일 3회이며 회원은 무제한이다. 광고는 편집·결과·My 본문과 분리된 오른쪽 300×600px 배너 자리로 구성한다. Home·로그인·회원가입에는 광고가 없고 1280px 미만 화면에서는 배너를 숨긴다.

문서별 변경과 검증 결과는 [문서 업데이트 요약](문서_업데이트_요약.md)을 먼저 확인한다. 보존 원본은 docs/ver1에 있고 이번에 수정하지 않는다.
